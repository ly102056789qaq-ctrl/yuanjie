# 战斗 HUD 迁移对照（来源：main 上的 battle.css / battle.html）

迁移到 Cocos 时按这份还原，不重新设计。百分比是相对 16:9 舞台，vh 换算按设计分辨率 1920×1080（1vh = 10.8px）。

## 总原则
- 无底板。每个组件自己有切角、描边、材质、投影，直接浮在战场上。
- 文字统一白字 + 深色描边（#1A2430，1px 八向）+ 投影 `0 2px 3px rgba(10,16,28,.45)`。
- 字体：正文 YJ Sans；数字 YJ Wide（字宽 85%，粗体，等宽数字）；大字 YJ Title；衬线 YJ Serif。
- 切角 12px（技能）/ 8px（行动条头像），右上角斜切。
- 强调色 #3DB7D6；我方血 #3EEA96 系；敌方血 #F25555 系；韧性 #7BA3E0 系。
- 槽底 #1A2A28，外描 1px #0A1413，内阴影。

## 已知现状
- 能量点、暂停、倍速、自动、支援、瞬时调度仍是「数据锁定」，迁移时保持锁定样式（不透明度 .78–.8）。
- 资源：头像 `assets/battle/*-face.webp`、半身 `*-bust.webp`、状态图标 `assets/battle/icons/`、噪点 `assets/battle/ui-noise.png`。

## 已定稿的决定（2026-11-17）
- 血条采用方案 B（星铁式细条）：我方 7px、首领 9px；槽 `rgba(10,16,24,.55)` + 1px 黑描边；填充顶部 1.5px 亮白线 + 下方纯色渐变，带一层同色淡辉光；扣血残影为白色；无刻度。能量条 3px，`#7FE3FF` 带辉光。对照稿 `design/hud/hpbar-study.html`。
- 角色状态栏不要深色底板，头像直接浮着；四人之间留 34px 间距；名字不显示，元素图标贴血条左端，生命数字压在条上方。
- 数字为粗斜体窄字，3px 深色描边。
- UI 部件不用 AI 生成（测试过，效果偏素材商店）；生图只考虑用于场景与特效贴图，且每次先征得同意。
