## 文件怎么分

| 位置 | 用途与并行约定 |
|---|---|
| `battle3d/index.html`、`battle3d/stage-route.js` | 前者是可玩 HUD 的页面骨架，后者设置战场 iframe。当前默认 Unity，本地预览可显式加 `?engine=unity`。 |
| `battle3d/play.css`、`battle3d/play.js` | 两个窗口共用。UI 窗口按具体组件做小补丁，例如 `#dock`、`#stpanel`。伤害数字 `.fl`、`floatDamage`、命中演出 `present()`、领域事件和 `#domainbanner` 归战斗窗口。两边编辑前先看当前文件和差异。 |
| `js/battle/`、`data/skills/`、`data/battle/` | 回合状态、能量、伤害和技能配置的数据来源。显示层读现有数据，方便手动、自动和倍速共用。 |
| `unity/Battle/`、`battle3d/unity/` | 战斗窗口维护。单改网页 HUD，刷新浏览器即可看见。 |

## 踩过的坑

| 现象 | 已验证的原因与做法 |
|---|---|
| 改了页面，下一次生成又回去了 | `cocos/tools/make_overlay.py` 从 V6 整页生成 `battle3d/index.html`。改 DOM 时核对模板和生成脚本，生成后看差异，尤其要保留 Unity 入口。单改 `play.css` 或 `play.js` 直接刷新。 |
| 稿上看着正好，实战面板、选中箭头或飘字却偏了 | 网页 HUD 有自己的舞台缩放，Unity 在 iframe 的 canvas 内绘制。跟人物走的元素沿用 `screenPos`／`posOf` 的坐标换算。用全画面和一次近景分别检查。 |
| 截下来只有冰面和人物，界面全没了 | `#stage` 是 Unity 画布。验 HUD 要截父页面，并等 `window.yjHud?.battle` 可用且 `#dock` 退出 `idle`。本次基准就是整页截图。 |
| 点过战场后快捷键失灵，或按一次执行两次 | 父页和 iframe 都有键盘处理。修改选择、确认交互时，分别在点击网页按钮和点击战场后试一次 `Q/E`、`A/D`、空格。保留同键二次确认。 |
| 自动化浏览器里大招视频播不出 | 本机已用 Playwright 的 `channel: 'msedge'` 验证 H.264 视频。实机服务用上文的 `serve.py`，它处理模块脚本 MIME。 |
| 旧截图看起来像新修复没生效 | 以前在 WebGL 构建退出前抓过旧画面。改到 Unity 后，等日志 `Exiting batchmode successfully` 再用新浏览器上下文实测。纯 HUD 迭代省去构建。 |
| 肩膀断口被当成图片糊，来回补图 | 思惟诺姆右肩的断层随抬手出现，保留贴图、校准肩轴及蒙皮权重后已实机对比。以后先区分静态清晰度与运动接缝，保留原始 PNG/PSD 和整只手入镜的动作帧。 |
| 商品页漂亮，实战看不出买的特效 | 资源在电脑上、导进工程、具体招式实际调用，是三个独立环节。Imagy VFX 1.0.5 和 Damage Numbers Pro 4.56 的本地文件已确认，接入和实机验证由战斗窗口执行。特殊命中验真实事件，幻海分别看展开、持续与退场。 |

## 战斗窗口本轮实测

打开 [幻海实机预览](http://127.0.0.1:8765/battle3d/?engine=unity&preview=illusion)，进场点一下空白处即可开启声音。该预览给思惟诺姆充满能量，在可操作回合自动插入终结技。普通入口依照正式规则积攒能量。

Unity 已使用 Imagy 的 Shinto 粒子、Plexus 粒子和纹理，以及 Triple-A MOBA 的施法和命中预制体。普通数字按用户截图调整；Damage Numbers Pro 的紫色 Neon Text 用于幻象复现，金色 Gold 用于现实覆写。实机验证覆盖幻海展开、到期关闭及两种特殊数字，金色样例来自升格 VI 的测试对局。

战斗页按动作播放施法、普通命中、重击、幻海展开和消退五个音效。音频为本地合成。目标身上的瞬时亮光位于 Unity 画布上方，随目标的屏幕位置移动。项目保留固定月光，领域调色和水波绘于 Unity 场景内。UI 窗口若处理全屏叠层，请在亮色冰面与深蓝幻海上各验一次。
